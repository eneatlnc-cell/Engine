# Engine ECS 过渡部署手册 (阿里云)

> **定位: 极早期过渡方案**。用现有阿里云账号快速起一个可测的中继环境,
> 避免为新购 VPS 走付款/开通流程。通用部署步骤 (systemd/Nginx TLS/验收/
> 运维) 与正式 VPS 部署完全一致, 见 [VPS_DEPLOY.md](VPS_DEPLOY.md);
> 本文只写 **ECS 特有的部分**——实例购买、安全组、云上特有排障。
> 规模起来后按 VPS_DEPLOY.md 迁移正式环境, 中继零落盘, 迁移只需改 DNS。

## ECS 与通用 VPS 的差异一览

| 环节 | 通用 VPS | 阿里云 ECS | 本文章节 |
|---|---|---|---|
| 第一层防火墙 | 无, 只有系统内 ufw | **安全组** (控制台, 默认拒绝一切入方向) | §2 |
| 购买选型 | 任意主机商 | 地域/规格/计费方式有讲究 (备案/突发型积分) | §1 |
| 网络阻断 | 无 | 内地域未备案域名 80/443 被拦截页拦停 | §5 |
| 证书 | certbot 即可 | certbot 亦可; 阿里云免费证书需手动续, 不推荐 | VPS_DEPLOY §4 |
| 系统内其余步骤 | — | **完全相同** (Ubuntu 22.04 + apt) | VPS_DEPLOY §2-§10 |

## 1. 购买 ECS (选型要点)

控制台: 云服务器 ECS → 创建实例, 按下表选:

| 项 | 建议 | 原因 |
|---|---|---|
| 地域 | **香港** (或新加坡) | 内地域 (杭州/北京等) 的 80/443 Web 服务要求域名 ICP 备案 (个人首次约 1-3 周), 未备案会被拦截页拦停, `wss://` 同样受管; 海外地域无此要求, 香港对大陆延迟 30-80ms |
| 规格 | 2C2G 突发型 (t6) 最便宜即可 | 中继是长连接 IO 密集型, CPU 需求极低; t6 有 CPU 积分限制, 但日常聊天场景积分够烧, 极早期人少时无感 |
| 镜像 | 公共镜像 **Ubuntu 22.04** | 保证与 VPS_DEPLOY.md 的 apt 命令一致 |
| 系统盘 | ESSD Entry 40GB | 中继零落盘, 最小盘即可 |
| 带宽计费 | **按使用流量**, 峰值 50-100Mbps | 中继是全流量必经点, 按流量计费比固定带宽省钱; 峰值带宽别设太低 (如 5Mbps 高峰会卡消息) |
| 登录 | 密钥对 (推荐) | 免密码, 比密码安全 |

> 已有 ECS 的话直接复用: 任意闲置 2C2G 及以上实例均可, 确认装/换 Ubuntu 22.04 就行。

## 2. 安全组 (ECS 部署的第一坑)

安全组是实例外层的云防火墙, **默认拒绝所有入方向**——不配规则 443 就是全断,
App 永远「连接中」, 且实例内 `ss -tlnp` 看一切正常, 极易误判为服务故障。

控制台: ECS 实例详情 → 安全组 → 配置规则 → 入方向, 逐条添加:

| 协议 | 端口 | 授权源 | 用途 |
|---|---|---|---|
| TCP | 22 | 你的 IP/32 (或 0.0.0.0/0 + 密钥登录) | SSH |
| TCP | 80 | 0.0.0.0/0 | Let's Encrypt HTTP-01 签发与续期 |
| TCP | 443 | 0.0.0.0/0 | wss:// 入口 |

> 8080 **不加规则**即天然不对外 (中继仅监听 127.0.0.1, 双保险)。
> SSH 源填 0.0.0.0/0 时务必用密钥登录并考虑装 fail2ban。

## 3. 域名解析

云解析 DNS (或任意服务商) 加 A 记录: `relay.example.com → ECS 公网 IP`

```bash
dig +short relay.example.com   # 返回 ECS 公网 IP 即生效
```

> 域名在阿里云且 ECS 在内地地域, 未备案时解析后访问 80/443 会被拦截
> (见 §5); 香港地域不受影响。

唯一可选补充——系统内 ufw 作为第二层 (安全组之上再加一道保险):

```bash
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw deny 8080/tcp && ufw enable
```

## 5. ECS 特有排障

| 症状 | 根因与处理 |
|---|---|
| 公网 curl 443 直接 TCP 超时 | **安全组没放行 443** —— ECS「连不上」最高频根因; 回 §2 补规则。实例内 `ss` 看着正常没用, 安全组在系统外层 |
| 80/443 通了, 但返回阿里云拦截页 | 内地域 + 域名未备案被拦 —— 换香港地域实例, 或走 ICP 备案流程 |
| 高峰期全员卡顿、消息延迟 | ① 峰值带宽设太低 → 控制台调高; ② t6 突发型 CPU 积分耗尽 → 云监控看「CPU 积分余额」, 归零即性能骤降 |
| `apt-get` 卡在 Security 更新 | 部分公共镜像源为阿里云内网源, 公网带宽计费下无碍; 也可换 `mirrors.aliyun.com` (公网) 加速 |
| 云监控没数据 | 老镜像可能没装云监控插件: 控制台 → 实例 → 运维与监控 → 安装插件 |

通用排障 (证书/握手 400/404/IP 限流等) 见 [VPS_DEPLOY.md §10](VPS_DEPLOY.md#10-排障速查)。

## 6. 过渡期结束后的迁移

中继零状态零落盘, 迁移到正式 VPS 只需三步:

1. 新 VPS 按 VPS_DEPLOY.md 完整部署
2. DNS A 记录改指向新 VPS IP
3. 等客户端重连 (自动恢复, 无需升级 App)

ECS 实例验证线上无流量后即可停机/释放。
